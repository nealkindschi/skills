## Scoring Guide

| Dimension | 2 points | 1 point | 0 points |
|---|---|---|---|
| Proprietary Data | Internally generated dataset or original survey | Novel analysis of third-party data | No original data |
| First-hand Evidence | Screenshots, transcripts, tool outputs | Paraphrased anecdote | No evidence |
| Original Framework | Named new methodology or checklist | Modified existing framework | No framework |
| Expert Attribution | Named author with verifiable credentials | Named author, no credentials | Generic or anonymous |
| Freshness Hook | Tied to 2025-2026 event/data cut | Year mentioned, no specific date | Timeless/undated |

See `references/rubric-details.md` for edge cases and expanded examples.

## AI/LLM Optimization Checks

- [ ] Schema markup applied (Article + any applicable: Dataset, FAQ, HowTo)
- [ ] Each H2 contains one extractable standalone sentence
- [ ] Highest-IG claim within first 150 words
- [ ] Heading hierarchy (H1 → H2 → H3) — no skipped levels
- [ ] All data points attributed with source and date
- [ ] No "studies show" / "research indicates" without named source
